# ЦифроМавка

Мова програмування для Матерії (концепт).

```цифромавка
договір Монета
  випускач адреса
  баланси {адреса => природне}

  дія чародія()
    я.випускач = повідомлення.надсилач
  кінець

  дія випустити(отримувач адреса, кількість природне)
    вимагати повідомлення.надсилач == я.випускач
    вимагати кількість < 1е60

    я.баланси[отримувач] += кількість
  кінець

  дія надіслати(отримувач адреса, кількість природне)
    вимагати кількість <= я.баланси[повідомлення.надсилач] : "Недостатньо коштів.";

    баланси[повідомлення.надсилач] -= кількість;
    баланси[отримувач] += кількість;
  кінець
кінець
```
